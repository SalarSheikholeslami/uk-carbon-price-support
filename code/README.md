# Code — UK Carbon Price Support and the Electricity Mix

**Seminar research project | Synthetic Control Method (SCM)**  
**Author:** Salar Sheikholeslami  
**Institution:** Johannes Kepler University Linz  
**Software:** Stata

## Overview

This directory contains the Stata `.do` files used to produce the figures, tables, and robustness checks for the seminar paper **“The Effect of the UK Carbon Price Support on the Electricity Mix: Synthetic Control Evidence on the Combined Coal and Gas Share of Electricity Generation.”**

The analysis uses the **United Kingdom** as the treated country, the introduction of the **Carbon Price Support in 2013** as the intervention, and annual country-level observations for **2001–2019**. The main outcome is the **combined coal-and-gas share of total electricity generation**. A synthetic UK is constructed from a donor pool of 20 countries.

## Requirements and input data

- **Stata**, with the user-written `synth` command available (`ssc install synth`). Some scripts check for and install it automatically.
- Original CSV input files with the column names and layout expected by the scripts:

| Input CSV | Used for |
|---|---|
| `share-electricity-source-facet3.csv` | Main outcome and fuel-mix comparisons |
| `GDP per capita.csv` | GDP-per-capita predictor |
| `electric consumption per capita.csv` | Electricity-consumption predictor |
| `manufacturing-value-added-to-gdp.csv` | Manufacturing-share predictor |
| `carbon-intensity-electricity.csv` | Figure A2 carbon-intensity comparison |
| `annual-co2-coal.csv` | Figure A2 coal-emissions comparison |

**The source CSV files are not included with these scripts.** Their structure matters: the GDP and electricity-consumption imports, for example, expect header information on multiple rows. Data downloaded in a different format may need to be adjusted.

## Running the analysis

1. Obtain the six input CSV files and place them in a local project directory.
2. **Edit the file paths in the `.do` files before running them.** Several scripts use hard-coded Windows paths (such as `C:\Users\Salar\Desktop\CPS\`), and others define a `local root` path. Changing Stata's working directory alone is **not sufficient**.
3. Install `synth` if necessary, then run the relevant `.do` file from Stata. Start with the **Figure 1, Panel A** or **Figure 1, Panels A–B** script for the baseline estimation.
4. Run the mechanism, placebo, and robustness scripts as needed. Some scripts generate intermediate `.dta` files, including `synth_CPS_coal_gas_share.dta`, `base_panel.dta`, and `panel_ready.dta`, which other scripts use. In particular, the leave-one-out scripts require `panel_ready.dta`, generated by the backdating scripts.
5. **Update the paths to other `.do` files** inside the Figure 1 gap-plot and table scripts; they explicitly call the baseline Figure 1 script. Some figures appear in Stata's Graph window rather than being exported automatically.

## Reproducibility notes

These files document the original seminar-project analysis. They are **not a verified, one-command replication package**: the source datasets are not bundled, the original absolute file paths require editing, and the scripts have not been retested together in a clean environment. The mechanism plots are descriptive; they should not be interpreted as separate causal estimates.

For the research design, results, and interpretation, refer to the [main repository README](../README.md) and the seminar paper.
